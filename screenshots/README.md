# Screenshots

Dieser Ordner enthält die Bilder, die in der Haupt-[README.md](../README.md) eingebunden sind.
Sobald du die Dateien mit den unten genannten **exakten Namen** hier ablegst, erscheinen sie
automatisch in der README – es ist keine weitere Änderung nötig.

## Benötigte Dateien

| Dateiname | Zeigt | In README |
|---|---|---|
| `dashboard.png` | Dashboard (Kennzahlen, Maßnahmen, Verteilung) | Großes Titelbild |
| `bewertung.png` | Bewertungserfassung / Fragebogen | Galerie |

| `trends.png` | Trend-/Kategorie-Analysen (Diagramme) | Galerie |

Optional (gern ergänzen, dann sage mir Bescheid, ich binde sie ein):
`login.png`, `pdf-export.png`, `dark-mode.png`, `ziele.png`, `cross-db.png`.

## ⚠️ Wichtig: keine echten Daten zeigen

Das Repo wird öffentlich. Bitte **keine realen Lieferanten, Namen oder Bewertungen**
abfotografieren. Am einfachsten: eine **frische Demo-Datenbank** mit erfundenen Einträgen
verwenden (z. B. „Muster GmbH", „Beispiel AG", „Technik Nord", „Süd-Components").
Über den Datenbank-Wechsel in der App lässt sich dafür bequem eine separate `.db` anlegen.

> Wenn du möchtest, kann ich dir vorab eine kleine Demo-Datenbank mit Beispiel-Daten
> erzeugen, damit die Screenshots gleich realistisch und gefüllt aussehen.

## Tipps für gute Screenshots

- **Fenstergröße** einheitlich, z. B. 1400×900 (Standardgröße der App) – wirkt aufgeräumt.
- **Ein Theme** durchziehen (Light wirkt in READMEs meist ruhiger; Dark optional als `dark-mode.png`).
- **Format PNG**, möglichst nur das App-Fenster (ohne Desktop/Taskleiste) – unter Windows `Alt`+`Druck`.
- **Dateigröße** im Rahmen halten (Breite ~1600 px reicht; bei Bedarf leicht komprimieren), damit das Repo schlank bleibt.
- Sensible Spalten ggf. ausblenden – aber mit Demo-Daten erübrigt sich das.

## Alternative: eigene Galerie-Seite

Falls viele Screenshots zusammenkommen, lässt sich daraus auch eine eigene Seite
(`SCREENSHOTS.md` oder `docs/`-Galerie) machen und aus der README verlinken. Sag einfach Bescheid.
